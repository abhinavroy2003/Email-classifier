# Email Spam Classifier

## 📌 Project Overview
This project is a basic machine learning application that classifies emails as **Spam** or **Not Spam** based on their content. It helps in filtering unwanted emails and keeping the inbox organized.

---

## 🚀 Features
- Classifies emails into **Spam** and **Not Spam**
- Uses basic **Natural Language Processing (NLP)**
- Simple and beginner-friendly implementation
- Can be extended with more advanced models

---

## 🛠️ Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- NumPy
